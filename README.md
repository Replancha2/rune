# Rune Game Mobile App

## Dependencies:

- [NodeJS LTS](https://nodejs.org/en/)
- [AndroidStudio](https://developer.android.com/codelabs/basic-android-kotlin-compose-install-android-studio?hl=es-419#0)

## Installation:

- Clone the repo:
```
git clone https://github.com/Replancha2/rune.git
```
- Install necessary npm packages
```
cd rune
npm install
```

## Run the program:

- Android `npm run android`
- IOS `npm run ios`
- Web `npm run web`
